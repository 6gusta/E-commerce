# 🛒 E-commerce Full Stack

Projeto de **e-commerce completo**, desenvolvido com **Angular no front-end** e **Spring Boot no back-end**, com foco em **segurança, integrações reais e boas práticas de mercado**.

---

## 🚀 Tecnologias

**Front-end**
- Angular
- TypeScript
- HTML5 / CSS3

**Back-end**
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Spring Mail
- RabbitMQ
- Stripe API (PIX e Cartão)

**Banco de Dados**
- MySQL / PostgreSQL

---

## 🔐 Segurança

- Autenticação e autorização com **Spring Security**
- Controle de acesso por nível:
  - **Administrador**
  - **Cliente**
- Separação de permissões para garantir a segurança da aplicação

---

## 📦 Funcionalidades

- Interface com níveis de segurança (admin / cliente)
- Cadastro e gerenciamento de produtos
- Pesquisa dinâmica e filtros de itens
- Finalização de pedidos com **Stripe** (PIX e Cartão)
- Envio de e-mails automáticos com **Spring Mail**
- Processamento assíncrono com **RabbitMQ**
- Painel administrativo para gerenciamento de pedidos
- Histórico de pedidos com filtros semanais

---

## 🧠 Objetivo do Projeto

Projeto desenvolvido para consolidar conhecimentos em **desenvolvimento full stack**, integrações reais, autenticação/autorização e comunicação entre serviços.
